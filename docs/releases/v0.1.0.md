# Neon HUD 0.1.0 — public preview

The first public preview brings a tiny neon performance HUD to Windows and macOS.

## Release highlights

- **Tiny floating HUD:** CPU speedometer, RAM, network and configurable multiple-drive storage in a 360 × 240 panel; expand for detail.
- **Stress you can read:** green → amber → hot pink gradients, numerical measurements, **!** pressure indicators and hover explanations.
- **Smart resource mode:** CPU/RAM pressure or high reported temperature slows checks, quiets animation and shows a recovery strategy with suggested actions.
- **Playful neon design:** three themes, interactive icons and finite chaotic bursts, with Playful/Quiet and reduced-motion options.
- **AI allowance and drain:** supported Codex/Claude Code sources, reported five-hour/weekly windows, countdowns and averaged allowance-drain warnings.
- **Attention at a glance:** question/permission badges and brief icon shakes for connected Claude Code sessions.
- **Desktop controls:** tray/menu-bar access, right-click/keyboard menu, pause/refresh, pinning and optional login startup.
- **Appearance-first setup:** labeled sample preview, optional Connections, then Preferences.
- **Open source:** MIT OR Apache-2.0, dependency notices and bundled font/animation licenses.

## Downloads and setup

Download the **Windows x64 setup .exe** or **universal macOS .dmg** from this release. Mac supports Apple Silicon and Intel. SHA256SUMS.txt records asset hashes.

Windows: run setup. Mac: open the DMG and drag Neon HUD into Applications. First launch guides you through Appearance, optional Connections and Preferences. Turn on **Launch Neon HUD at login** if desired. Tray/menu-bar **Configure** opens settings; **Quit** exits.

Preview installers are **unsigned**. Platform signing and macOS notarization are not included. Native Mac install/runtime checks and full-process resource measurements are pending.

## Measurements and limits

Codex reads Codex account allowance, not ordinary ChatGPT chat quotas. An automatic ChatGPT chat usage source is unavailable. Claude readings require the optional Claude Code bridge. Five-hour windows appear only when reported. Current quota sources do not expose cumulative spent tokens; the drain estimate uses allowance percentage against elapsed time and is not a provider guarantee.

Temperatures require supported sensors. Thermal throttling is not measured. Network colors show relative activity rather than capacity. Remove the Claude bridge through Connections before uninstalling so its settings do not retain a deleted executable.
