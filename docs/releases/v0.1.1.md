# Neon HUD 0.1.1 — Pocket chaos

This preview shrinks the default HUD to a 280 × 56 floating side pill. CPU, memory, network, selected-drive capacity and AI allowance keep their icons, gradient bars and numerical values. Hover for exact measurements; click for full gauges and graphs; right-click for quick controls. Three neon themes, expressive interaction transitions, brief question shakes and quiet/reduced-motion options remain available.

Connection buttons now show progress immediately, prevent overlapping actions and report the actual source state. Claude **Bridge enabled** confirms the statusline and all seven hooks; **Waiting for readings** stays visible until real usage arrives. Claude Code sign-in remains provider-managed. Ordinary ChatGPT chat quotas are unavailable; Codex account allowance is labeled separately.

Automatic updates check GitHub at startup and every six hours, defer under resource pressure, and download packages with mandatory signature verification. **Install & restart** requires a click. Windows x64 setup, universal macOS DMG and the universal signed Mac update archive are release assets. Update signatures are distinct from OS code signing; these preview installers are not OS code-signed or notarized.

For an existing installation, run the new installer and choose **Appearance → Pill** if your saved layout is expanded. From 0.1.1 onward, future releases can use the updater in Preferences. System monitoring, adaptive sampling, configurable drives, optional startup and tray access remain available.

See [validation](../VALIDATION.md), [changelog](../../CHANGELOG.md) and [release maintenance](MAINTENANCE.md). Native Mac installation and full-process performance targets require separate measurement. Rust powers the native backend; Tauri's WebView renders the interface.
