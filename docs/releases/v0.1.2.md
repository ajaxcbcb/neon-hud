# Neon HUD 0.1.2 — Tiny turbo

The floating pill now includes GPU activity. Select a saved adapter or follow the busiest reported GPU, then expand for every adapter's identity, available activity and memory, measurement source and limitations. Windows uses cached DXGI/PDH system counters; Mac uses Metal identity. Unsupported global readings and stale samples stay unavailable.

CPU, memory and network can sample every 250, 500, 1000 or 2000 milliseconds. GPU checks remain at one second and sensors at two seconds in normal mode. AI allowance remains independently polled at five seconds; polling faster does not invent new provider usage. Short meter transitions follow the display refresh rate and stop when settled. Numbers show the actual latest sample; native frame rate has not yet been measured.

GPU pressure joins the adaptive strategy. Sustained high load and reported heat warn with an exclamation badge, slow checks to 4–8 seconds and quiet motion. Recovery requires fresh readings from the GPU which caused the pressure. Hidden windows stop polling and motion; reopening resumes monitoring immediately.

The 280 × 56 pill, three neon themes, brief question shakes, seven-hook Claude Code bridge, tray access, optional startup and signed updater remain available. Existing settings preserve their saved choices and gain GPU/250ms defaults. Install the Windows x64 setup or drag the universal Mac app from the DMG. Version 0.1.1 users can use Preferences → Check for updates → Install & restart once the release is published.

Preview installers are not OS code-signed or notarized; updater payloads have a separate mandatory signature. Native GPU accuracy, actual frame rate, Mac installation and full-process performance require installed-platform evidence.
