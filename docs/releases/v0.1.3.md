# Neon HUD 0.1.3 — Quiet upgrades

Preferences now offers **Automatically install updates and restart**. Enable it for future signed releases to install after the downloaded package has waited a minute and the HUD has had no interaction for a minute. Checks run on startup and every six hours, including from the tray or Mac menu bar.

Open settings or details, unanswered questions, connection attempts, paused monitoring, unsaved preferences and high pressure defer the restart. A fresh system/provider preflight checks again immediately before installation; missing readings wait. Preflight runs at most once per minute while a verified package is ready. Installation failures wait for a manual retry.

Existing settings, themes, placement, startup choice and Claude bridge survive upgrades. Automatic installation starts off for existing users; manual **Install & restart** remains available. Version 0.1.0 users need the Windows setup or Mac DMG once to gain the updater.

Saved profiles tolerate missing fields from older versions. Unreadable settings are retained, and pending edits finish saving before tray Quit or an update. On Windows, Minimize hides the window to the tray and removes its taskbar presence; **Show HUD** or **Configure** restores it.

The GPU pill, adjustable sampling and display-synced transitions from 0.1.2 are included. Preview installers are not OS code-signed or notarized. Application update payloads have a separate mandatory cryptographic signature. See [validation](../VALIDATION.md), [changelog](../../CHANGELOG.md) and [release maintenance](MAINTENANCE.md).
