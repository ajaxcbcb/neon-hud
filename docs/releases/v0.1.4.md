# Neon HUD 0.1.4 — Move your little pill

Drag the six-dot grip to place the HUD anywhere on a display. Focus the grip and use arrow keys to nudge it by ten physical pixels, or hold Shift for one pixel. The custom location and chosen size save in your existing profile. Hover details, settings and tray restoration reuse that location; monitor changes clamp the window into the available work area.

Right-click and choose **Compress pill** for a 160 × 56 window. It shows the most stressed enabled system metric alongside Codex and Claude allowance icons, numerical readings, warning badges and question reactions. With AI metrics disabled, it shows up to three system metrics. Hover for details or click for the existing full meters. **Uncompress pill** returns to 280 × 56; **Reset position** restores the selected corner. All three sizes are available on the first configuration page.
