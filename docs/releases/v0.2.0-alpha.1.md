# Neon HUD 0.2.0-alpha.1 — native desktop preview

Neon HUD now has a Rust desktop renderer. The floating capsule, settings and instruments are drawn directly in OS windows with egui/glow. Configuration uses fixed tabs and drive pages, without a scrolling dashboard.

- **Tiny by default:** new profiles start at 160 × 56 logical pixels. Regular mode is 280 × 56; imported profiles retain their saved size.
- **Desktop controls:** drag the grip, double click to compress, hover for readings, click for instruments and right click for quick controls. The tray provides Show, Settings, Compress and Quit.
- **Your neon layout:** a custom rounded frame, drag header, three numbered Appearance/Connections/Preferences steps, theme cards, motion tiles and a sample pill preview. Preferences contains Instruments and Startup choices. Storage choices use pages to fit multiple drives; settings never scroll.
- **Neon instruments:** Circuit, Cyberpunk and Aurora themes; custom metric icons; gradient gauges and bars; numerical readings; brief hover and question reactions that stop under pressure or reduced motion.
- **System and allowance readings:** CPU, GPU, RAM, network and selected drives use the existing Rust core. Codex and Claude show reported quota windows, including five-hour limits when supplied, plus average drain and a warning when the current pace could exhaust allowance before reset.
- **Retained preferences:** a separate preview profile imports existing settings once. Preview startup is opt-in and has its own OS registration. Claude bridge readings remain shared with the installed application.

## Downloads

Windows: extract the portable ZIP and run `neon-hud-native.exe`. Mac: open the app from the DMG or ZIP. Packages contain Apache 2.0/MIT licenses and notices. `SHA256SUMS.txt` identifies the published files.

This is an unsigned preview for Windows x64 and Apple Silicon Mac (arm64). The Mac package is not universal and does not support Intel Macs. It does not replace the installed v0.1.4 or use the existing automatic-update manifest. The native renderer requires OpenGL 2.0 or later from the computer's graphics driver.

## Validation and remaining work

Exact-source Windows/Mac tests, dependency checks, packaging and Windows rendered-window inspection are recorded in [validation](../VALIDATION.md). A rendered Windows preview is distinct from installation and interaction checks on the user's computer.

Codex and Claude still use connector helpers. Strict single-process connectors, signed native automatic updates, target-machine tray/drag/startup verification, Mac runtime and full-process performance measurements remain open. Ordinary ChatGPT allowance, token counts and unsupported sensors are shown as unavailable when the source does not report them.
