# Neon HUD 0.2.0-alpha.3 — app icon and quick controls

Right-clicking the floating HUD now opens a complete, small native controls popup. The old menu used a hover-only response and could be clipped inside the 56-point pill.

- Right-click a metric, the drag grip or the pill background. Shift+F10 is also available when the HUD has focus.
- Open Settings, compress or expand the pill, pause or resume monitoring, hide to the tray, reset the position or quit.
- Controls open toward available screen space. Escape, the close button or switching focus dismisses the popup.
- Windows executables, native windows and the tray share the Neon N program icon. Desktop and Start menu shortcuts use the executable's embedded icon. The macOS app includes its existing ICNS mark.

## Validation

Release checks are pending. Acceptance requires both locked platform builds and core regression tests, native icon decoding and compact-menu layout tests, actual Windows right-click input at eight edges/corners, every menu action and Escape dismissal. Installed Windows verification requires a separately admitted runtime phase; Mac interaction remains unverified.

## Downloads

Windows x64 uses a portable ZIP. Apple Silicon Macs have an app ZIP and a DMG. Packages include the Apache 2.0 and MIT licenses, third-party notices and font licenses; release checksums are provided.

This remains an unsigned native preview. Strict single-process provider connections, signed native automatic updates and Intel Mac packaging remain unfinished. Existing native preferences are retained, and the stable updater manifest remains unchanged.
