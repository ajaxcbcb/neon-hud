# Neon HUD 0.2.0-alpha.4 — visible update activity

The Download update action now stays visible and disabled while the update worker is busy. Hovering identifies the signed release version. The status and activity indicator tell you whether the HUD is checking, downloading, ready to restart or up to date; repeated checks remain disabled until the operation finishes.

This release retains the compact floating pill, Neon N program icon and screen-aware right-click controls from alpha.3. Preferences → Startup & updates uses the signed native-preview channel. Automatic checks and low-pressure downloads can be enabled separately; Restart and update saves your settings and replaces the application after normal shutdown.

Publication requires locked Windows/macOS builds, core tests, eight-edge hover/right-click checks and every native menu action on Windows. A separate public release-to-release GUI test verifies alpha.3 → alpha.4, signed-file rejection, normal exits, the installed binary, startup acknowledgement and preference retention. Its result is recorded after execution.

Windows x64 portable ZIP and Apple Silicon Mac app ZIP/DMG include Apache 2.0/MIT and third-party licenses. Update archives and metadata have verifiable signatures; OS code signing and Mac runtime interaction remain unverified. Earlier previews need an initial installation to receive this updater. The stable updater feed is unchanged.
