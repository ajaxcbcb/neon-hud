A small black capsule now opens into a shallow row of media, calendar, notes, timer wheels, tasks and quick actions. Fine dividers and Nook/Tray navigation follow the observed NotchNook reference states. Your CPU/GPU/RAM/network/drive/Codex/Claude numbers remain visible in the bottom rail; instruments and AI detail views retain gradients, histories, reported five-hour reset windows, drain averages and attention indicators.

Hover to peek, click to open, pin to keep it open and press Escape to collapse. Choose **Appearance → Nook** after upgrading an existing profile. ## New tools

- Music artwork, playback progress, seek and transport controls from the Windows system media session; opt-in Music control on Mac.
- A week calendar with local ICS import, timezones, recurring events and all-day dates; opt-in native Calendar access on Mac.
- Notes with B/I/U, tasks with completion/favourites, timer wheels with 1/5/25-minute presets and a persistent file-reference Tray.
- An opt-in camera mirror that reports connected only after a validated frame arrives; capture stops when hidden or under resource pressure.
- Battery/AC status and quick actions for Settings, AI, pill presentation and mirror.

Notes, tasks, deadline timers, file references and utility choices use separate bounded, recoverable storage. Codex connection intent and last-known allowance survive retry errors with a visible stale/error state. Bridge migration recognises owned Windows and Mac version folders while preserving unrelated Claude settings.

## Install and update

Windows x64: extract the portable ZIP and run `neon-hud-native.exe`. Apple Silicon Mac: open the app from the ZIP or DMG. The packages include Apache 2.0/MIT and third-party notices. OS signing and notarization are not configured.

Alpha.3 and later can use **Preferences → Startup & updates → Check now → Download update → Restart and update**. Metadata and update archives are cryptographically signed; installation saves preferences, waits for normal exit and checks replacement startup. Automatic checks and downloads are separately configurable. Earlier previews require an initial installation. The stable WebView updater feed is unchanged.

## Evidence and limits

Publication requires exact-source locked Windows/Mac tests and builds, native dependency checks, real Windows pointer/keyboard controls, saved notes/tasks/timer receipts, screen-edge hover/right-click checks, normal Quit and inspected native frames. Results are recorded in [Validation](../VALIDATION.md) after execution. The alpha.4 → alpha.5 signed GUI update is checked separately after publication.

The reference study observed representative frames from five official clips. Exact animation timing has not been measured. Media/camera/calendar hardware behavior and Mac permission flows need target-platform runtime checks. Codex uses its official helper; connector-inclusive single-process operation and performance savings are not proved. Ordinary ChatGPT allowance and cumulative spent-token counts remain unavailable from supported sources.
