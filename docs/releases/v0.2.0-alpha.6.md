# Neon HUD 0.2.0-alpha.6 — native Nook, retained profiles and responsive Controls

The native black capsule opens into a shallow row of media, calendar, notes, timer wheels, tasks and quick actions. Hover to peek, click to expand, pin to keep it open, and press Escape to collapse. Nook/Tray navigation, fine dividers and the numeric system/AI rail follow the observed NotchNook reference states.

## Fixes in this release

- Right-click Controls opens on button press, avoiding a release-based click lost during hover transitions. Keyboard access with Shift+F10 remains available.
- Existing and imported profiles keep their floating pill on upgrade. Choose **Preferences → Instruments → HUD layout → Nook** to switch. Fresh profiles start in Nook, and explicitly saved choices survive restart.
- The hosted updater proof checks the compressed pill immediately after replacement startup. Profile regressions cover fresh, legacy and explicit presentation choices without changing settings, notes or running timers.

## Core features remain available

CPU/GPU/RAM/network/drive/Codex/Claude numbers, gradient instruments, histories, reported five-hour windows, allowance drain averages and attention indicators remain available. The movable compressed/regular neon pill retains its saved position. Settings uses the custom neon frame with fixed Appearance, Connections and Preferences steps.

Native utilities include music playback/seek, battery status, local ICS calendars, note B/I/U formatting, task favourites, timer presets and a persistent file-reference Tray. Camera mirror is opt-in and reports connected only after a validated frame; capture stops when hidden or under pressure. macOS offers opt-in Music and EventKit Calendar access.

Notes, tasks, deadline timers, file references and utility preferences use separate bounded, recoverable storage. Codex intent and last-known allowance survive retry errors with visible stale/error labels. Bridge migration preserves unrelated Claude configuration.

## Install and update

Windows x64: extract the portable ZIP and run `neon-hud-native.exe`. Apple Silicon Mac: open the app from the ZIP or DMG. Packages include Apache 2.0/MIT and third-party notices. OS signing and notarization are not configured.

Configuration starts at **Appearance**, then **Connections** and **Preferences**. Pick a theme and motion level, enable optional provider sources, and choose the layout/metrics/drives in **Preferences → Instruments**. **Startup & updates** controls opt-in login startup and the native update channel. There is no native Intel Mac package in this release.

| Action | Behavior |
| --- | --- |
| Hover / click Nook | Peek / expanded widget panel. |
| Pin / Escape | Keep Nook open / collapse. |
| Nook / Tray | Widget overview / local file-reference shelf. |
| Pill drag grip / double-click | Move / compress or restore. |
| Right-click / Shift+F10 | Settings, compression, pause/resume, hide, reset position and Quit. |
| Hide / OS tray or menu bar | Keep the utility running / restore or configure it. |

Existing profiles keep their saved presentation rather than being reset. Choose Nook explicitly to switch an existing pill profile. Retire old portable packages only after the verified replacement launches; retain profile and shared bridge data.

Alpha.3 and later can use **Preferences → Startup & updates → Check now → Download update → Restart and update**. Release metadata and archives are cryptographically signed; installation saves preferences, waits for normal exit and checks replacement startup. Automatic checks and low-pressure downloads are separately configurable; native restart requires the restart action. Earlier previews need an initial installation. The stable WebView updater feed is unchanged.
