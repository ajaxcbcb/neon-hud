# 0.2.0-alpha.7 candidate · Notch settings and connector repair

The installed native profile was incorrectly treated as isolated test mode because its folder is named `native-preview`. This blocked Codex Connect/Disconnect and saved-intent restoration. Alpha.7 makes test mode explicit: ordinary installs can connect, while isolated smoke runs cannot change real provider configuration.

Connections now displays the complete action result, current Codex state and whether Claude's shared bridge is enabled. Enable Claude once, then start or restart Claude Code to supply readings and questions. Configuration success and an actual allowance reading remain distinct.

Windows executable discovery prefers the installed OpenAI Codex desktop CLI, then native binaries on PATH, before older vendor fallbacks. Shell shims are not launched. Candidate ordering is covered by isolated tests; the target account connection still needs runtime proof.

Preferences → Notch adds Mini/Regular sizing, hover peek, auto-close, pin, screen selection and reset. Existing utility data and placement migrate without resetting notes, tasks, files or timers. Themes and selected metrics apply to Nook. Playful and Chaos use distinct finite easing; expansion keeps pointer targets stable and monitor scale is applied once.
