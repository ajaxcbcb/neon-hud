# Floating placement and compression

The HUD can be dragged by a small grip in its capsule, then compressed without losing its position. The existing full pill and meters remain available. Compression is a 160 × 56 logical-pixel window with a 152 × 48 capsule: the most stressed enabled system metric and the enabled AI allowance icons retain numerical readings, hover details, warning badges and question reactions. With AI metrics disabled, up to three system metrics are shown. A quick-control action expands the pill; Settings offers all three sizes.

Use the existing Circuit, Cyberpunk and Aurora tokens, Bricolage Grotesque labels and Space Mono tabular numbers. The grip is a subdued six-dot control with a grab cursor and visible keyboard focus. Motion only follows interaction or attention; reduced-motion and pressure controls retain priority. The signature detail is the small numerical allowance beneath each provider icon. Compression keeps the product a floating utility rather than adding another panel.

Persist size and a custom position in the same serialized profile. Position uses logical offsets from the selected monitor work area plus the monitor name; the actual monitor index breaks ties between identical display names. Monitor changes, DPI changes and smaller work areas clamp the window onscreen. Popovers grow toward free space from the saved location, and keyboard nudges use physical pixels. When a custom position exists, hover popovers, configuration, tray restoration and size changes must not dock the HUD back to a corner. Selecting a placement preset or Reset position clears the custom location. Programmatic placement never changes the saved location.

Existing profiles default to docked placement. Rust and frontend parsing accept the new size and nullable location, preserving every existing field. An unreadable profile stays untouched. A pending user move is captured before profile flush on Quit, restart or update.

Acceptance: meaningful geometry tests for negative monitor origins, mixed DPI, removed displays, compressed popovers and growth near screen edges; frontend and native profile round trips; type checking; build; independent review; admitted native dragging/compression/restart/tray verification. Installed v0.1.3 remains untouched until a tested replacement is admitted. This increment does not establish single-process compliance.
