# Native font asset

`Ubuntu-Bold.ttf` is embedded unchanged for settings headings and theme titles. Its Ubuntu Font Licence 1.0 and copyright notice are in `../licenses/UBUNTU-BOLD-LICENSE.txt` and `../licenses/UBUNTU-BOLD-COPYRIGHT.txt`, which are included in native packages. The copyright notice is reproduced from the font's name table (name ID 0); the upstream file named `COPYRIGHT.txt` contains only the license.
